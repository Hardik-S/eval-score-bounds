# Launch note

Version 0.1.0 provides an offline, standard-library score-fixture bounds check with exact decimal comparisons and a fixed, non-echoing invalid-input response. The included fixtures are synthetic demonstrations only. This tool makes no claims about evaluator quality or model performance.

The initial CI matrix covers Ubuntu and Windows with Python 3.10 and 3.13. This is a supported-platform check, not a claim of broader operating-system compatibility.
